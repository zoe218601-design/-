会跑、会扑、会炸毛的草莓猫 · 鱼干／小手指针版 · Windows

换新版
1. 先退出旧猫和旧鱼干；鱼干通过任务栏右下角的鱼干图标右键退出，恢复原指针。
2. 若旧版开启过自动启动，在旧版最外层运行 disable_autostart.vbs。
3. 将本压缩包全部解压到准备长期保存的位置。
4. 双击最外层 start.vbs，同时启动新版猫和玩具指针，不出现黑色窗口。
5. 你已经有 Python 和 PySide6，通常直接启动即可。缺依赖运行 cat/install.bat。
6. 想一起自动出现，在最外层运行 enable_autostart.vbs；取消运行 disable_autostart.vbs。
保持文件夹位置不变，移动后在新位置重新开启自启。

鱼干模式
默认使用约32像素的小鱼干，点击热点在鱼嘴。
小猫向鱼干跑动，中距离会跳起来，近距离会扑过去。
让鱼干停一下，猫咪追上会吃掉，咀嚼冒爱心，约1.2秒后鱼干回来。
消失期间暂时使用普通鼠标指针；停在原地会继续被吃。
打字时猫咪优先敲键盘，停止约2.5秒后再追鱼。
右键猫可关闭追鱼，或切换到睡觉模式。
跑、跳、扑动作随距离和冷却时间触发，不是每次都连放。

切成小手
任务栏右下角鱼干图标（可能藏在向上箭头里）→ 右键 → 小手：摸摸／挠痒痒。
指针变为约32像素的小手，点击热点在食指尖；猫咪停止追着吃。
点头／脸：闭眼享受、冒爱心、呼噜表情。
按住小手在猫身上轻轻移动：摸摸、挠痒。
点肚子（身体中下部）：炸毛、张嘴哈气。
点屁股／尾根（坐姿右下侧）：回头哈气、尾巴炸毛。
小手模式要搬动猫咪：Alt＋左键拖动。鱼干模式直接左键拖动。
右键猫可关闭“哈气声音”。声音是短促的合成气声，并非真实猫录音。
任务栏指针图标右键可切回鱼干。

闲下来
猫咪会依次舔爪、舔毛、抓地板，偶尔散步，活动模式不会自动入睡。
有鱼干在附近会优先追鱼。要看闲置动作，切小手模式或关闭追鱼，并停止打字。

找不到或退出
任务栏新增猫咪图标，右键“叫回小猫”可以把它放回当前屏幕中央。
猫：右键身体或任务栏猫图标 → 退出小猫。
鱼／手：右键任务栏玩具指针图标 → 恢复原指针并退出。
双击新版猫的 start.vbs 会叫回已经运行的新版；若旧版占用，则提示先退出旧版。
手动恢复原指针：fish/restore_cursor.vbs。
独立守护程序会在鱼干程序异常退出后恢复系统配置的指针。
取消自启不退出当前运行的猫和指针。

说明
需要 Windows、Python、PySide6，是源码包，不是独立exe。
修改仅作用于当前会话的系统光标，退出恢复，不改鼠标主题配置。
高DPI缩放后的视觉尺寸可能不同；浏览器自定义光标或游戏可能自行覆盖。
文字光标、调整大小等系统样式也统一替换为玩具，退出恢复。
猫和指针用本机回环地址交互，不连接互联网、不记录鼠标轨迹或按键。
追逐目前主要适用于猫所在的同一块屏幕。
无窗口启动需要Windows Script Host；用 start.bat 可显示错误。
真实Windows光标替换、自启、声音需在你的电脑上测试。

睡觉／活动模式（本版更新）
右键猫咪或任务栏猫图标 → 睡觉模式（保持睡觉）：一直睡。
打字、鱼干、小手摸摸、双击、拖动、叫回小猫都不会唤醒。
要醒来，主动选择“活动模式”或“活动模式：追鼠标”。
睡觉时仍可拖动换位置，但它保持睡姿。
活动模式保持活动，不再因闲置25秒自动睡觉。
模式自动记住，关闭再打开仍保持你选择的模式。
